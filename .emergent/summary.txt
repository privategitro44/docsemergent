<product_requirements>
The goal is to build a comprehensive documentation platform for a product named Emergent, with a visual style inspired by documentation sites like Replit's. The application must be light-mode only.

A key requirement is a built-in Content Management System (CMS) for managing the documentation content. This CMS must be accessible exclusively to administrators via a dedicated login page (e.g., ). The public-facing documentation, however, should be accessible to all users without any login requirements.

The CMS needs to support creating and editing articles that contain a mix of text, images, and videos. The system should allow both uploading new videos and embedding videos from external sources. A WYSIWYG (What You See Is What You Get) editor is sufficient for content creation.

Furthermore, the CMS must provide functionality to manage the site's navigation structure, allowing admins to add, remove, or reorder navigation links. The application should be pre-populated with minimal sample content that can be easily removed or replaced by the admin later.
</product_requirements>
